# docs/project — 项目过程记录

> **给 AI / 协作者：** 本目录记录目标、进度、决策与约定。  
> **不要**把进度清单写进根目录 `README.md`（README 只对外展示项目）。

## 文件索引

| 文件 | 用途 |
|------|------|
| [GOAL.md](./GOAL.md) | 学习/产品目标 |
| [STATUS.md](./STATUS.md) | 当前进度与待办 |
| [DECISIONS.md](./DECISIONS.md) | 架构与选型决策 |
| [CONVENTIONS.md](./CONVENTIONS.md) | 仓库约定（命名、目录、工具） |

开始新任务前，优先阅读 `STATUS.md` 与 `DECISIONS.md`。
