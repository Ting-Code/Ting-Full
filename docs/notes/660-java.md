## A1.1 语言特点 ★ · ○

**电子书：** `01 第一章 课程引言` → `01 Java语言特点.html`

### 我的摘要

电子书列了一堆「特点」；带学只抓岗位会问到的：

| 特点 | 一句话 | 要不要背 |
|------|--------|----------|
| 面向对象 | 万物皆对象，写业务/接口更贴日常建模 | ★ 认 |
| 简单 | 像 C++，但无指针、无多继承，类库多 | ★ 认 |
| **跨平台 / 结构中立 / 可移植** | `.java` → 字节码 `.class` → **JVM** 解释/执行；各 OS 有对应 JVM | ★★★ 必会 |
| 解释执行 | 先编译成字节码，运行时再变成机器码 | ★★ 认 |
| 健壮 | 强类型、编译期检查；GC 管内存 | ★★ 认 |
| 安全 / 分布式 / 高性能 / 多线程 / 动态 | 网络、并发、运行时装类库 | ★ 翻过即可 |

### 核心链路（默写）

```text
源码 .java  →  javac  →  字节码 .class  →  JVM  →  机器码
```

跨平台靠的是：**同一份字节码 + 各平台自己的 JVM**，不是「一份机器码到处跑」。

### 练习 / 口述

- [ ] 用一句话解释：Java 为什么说跨平台？
- [ ] （可选）本机执行 `java -version`，记下 JDK 版本。

### 面试短答

> Java 源码先编译成与平台无关的字节码，由各操作系统上的 JVM 加载执行，所以同一份程序可跨平台运行。

### 复盘

一星课：记住 **OOP + 字节码 + JVM** 即可，不必背完整「十大特点」名单。
